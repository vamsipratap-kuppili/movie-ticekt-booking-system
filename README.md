# 🎬 Movie Ticket Booking System

A simple console-based movie ticket booking system built in **Python**.

## Features

### Admin Section
- Add movies
- Add show timings
- Add seat numbers
- Delete show timings
- View all bookings

### User Section
- View available movies, shows & seats
- Book seats
- View booked seats

## How to Run

```bash
python movie_booking.py
